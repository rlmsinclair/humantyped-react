# Human Typed

A rather splendid little web application that proves you're not one of those pesky AI bots. Because apparently, that's a thing we need to worry about now.

## What's All This Then?

Human Typed is a sophisticated typing verification system that analyzes your keystroke patterns to confirm you're a proper human and not some silicon-based impostor. It's like a CAPTCHA, but instead of squinting at blurry street signs, you simply type as you normally would—a refreshing concept, wouldn't you say?

## Features

- **Text Editor**: A minimalist typing interface where you can pour out your thoughts, manifestos, or shopping lists. No judgment here.
- **Real-time Analysis**: Tracks your keystrokes with the precision of an overly attentive butler.
- **Typing Visualization**: Fancy charts that display your typing speed, because who doesn't want to see their words-per-minute fluctuate like the British weather?
- **Verification**: Generates a shareable URL proving you're human. Quite useful for those awkward moments when your friends suspect you've been replaced by a particularly eloquent chatbot.

## Technical Bits and Bobs

Built with a rather tasteful selection of modern web technologies:

- React (with TypeScript, because we're not savages)
- Vite (for that blazingly fast development experience we all pretend to understand)
- React Router (for elegant navigation, or as elegant as the web allows)
- Recharts (for those lovely visualizations that make the data look more important than it probably is)
- React Markdown (because formatting text shouldn't require a computer science degree)

## Getting Started

Rather straightforward, this:

```bash
# Clone the repository (assuming you have git installed, if not, well...)
git clone https://github.com/yourusername/humantyped-react.git

# Navigate to the project directory
cd humantyped-react

# Install dependencies (might take a while, perfect time for a cuppa)
npm install

# Start the development server
npm run dev
```

Then open your browser to `http://localhost:5173` and marvel at the technological wonder you've unleashed.

## Usage

1. Type something. Anything, really. A sonnet, your memoir, or that passive-aggressive email you've been drafting to your neighbor about their questionable recycling habits.
2. Watch in mild amazement as the chart tracks your typing speed.
3. Click "Verify My Typing" when you're finished.
4. Share the verification URL with skeptical acquaintances who doubt your humanity.

## Deployment

To build for production:

```bash
npm run build
```

This creates a `dist` folder with optimized files that you can deploy to your hosting provider of choice. Or just keep them on your hard drive as a digital keepsake. We won't judge.
